# Support

enquire-mcp is maintained in public. Pick the shortest route below so questions, defects, and security reports reach the right place.

## Get help

- Start with the [30-second quickstart](./docs/QUICKSTART.md) and run `enquire-mcp doctor --vault <path>` for an environment-specific readiness report.
- Ask configuration, architecture, and usage questions in [GitHub Discussions](https://github.com/oomkapwn/enquire-mcp/discussions).
- Report a reproducible product defect through [GitHub Issues](https://github.com/oomkapwn/enquire-mcp/issues/new/choose).
- Report a vulnerability privately using the process in [SECURITY.md](./SECURITY.md). Do not open a public issue for a suspected security problem.

## Include in a support request

- `enquire-mcp --version` and `node --version`
- operating system and MCP client
- the exact command or redacted client configuration
- relevant `doctor` output and the smallest reproducible sequence
- expected behavior and actual behavior

Remove bearer tokens, private vault paths, note contents, and other secrets before posting. A minimal synthetic vault is preferable to real personal data.
